05

How to master this topic

Understand

Explain the purpose of the concept in your own words. Identify the problem it solves and where it fits in a complete program.

Trace

Follow the program in execution order. Track changing variables, conditions, loop iterations, function calls and returned values.

Experiment

Change one thing at a time. Try normal, boundary and invalid inputs. Observe how the result changes and why.

Apply

Use the concept in a small independent program. Then combine it with earlier topics instead of learning each feature in isolation.

Before moving on, make sure you can:
  • Define the topic and explain why it is useful.
  • Recognise its syntax and the important parts of the code.
  • Write a small example without copying.
  • Explain what happens when the input or conditions change.
  • Identify at least one common error and how to correct it.
